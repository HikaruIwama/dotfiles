# やってはいけないこと

コミット作成時の禁止事項。

## コミットメッセージ

- `fix typo`だけのコミット。何のtypoか書く。
- 複数の無関係な変更を1コミットにまとめる。別々にコミットする。
- subjectを大文字で始める（日本語の場合は関係ない）。
- 過去形で書く（「追加した」ではなく「追加する」）。

## staging

- 対話的なstaging操作を使う（`git add -p`、`git add -i`など）。エージェントは実行できない。
- 包括的なstaging操作を使う（`git add -A`、`git add .`、`git add -u`）。無関係な変更を巻き込む。
- `git commit -a` / `-am`。indexを経由しないため。

## 履歴の書き換え

- `git reset`を使う。履歴を書き換えるため。ただし、ユーザーが明示的に指示した場合は除く。
- force-pushを使う。他の人の履歴が壊れるため。ただし、ユーザーが明示的に指示した場合は除く。

間違いを見つけた場合は、新しいコミットで修正するか、`git revert`で取り消す。詳細は`references/verification.md`を参照。
