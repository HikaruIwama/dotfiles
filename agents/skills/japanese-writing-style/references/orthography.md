# 表記辞書

`SKILL.md`の規範を適用するときに参照する、機械的に判定できる表記のルール。ここを書き換えれば、チームの表記方針を一箇所で変更できる。

## チームの決定事項

表記が割れやすい2点は、チームとしてこう決める。

- **カタカナ語の末尾長音は付ける。** サーバー、ユーザー、コンピューター、フォルダー。
  ただし慣用として定着している語は例外とする：セキュリティ、プロパティ、エンジニア。
  上記以外で判断がつかない語は、省略せずに用語統一表に追記し、以後はそれに従う。
- **英字と日本語の間にスペースを入れない。数字と日本語の間にも入れない。** インラインコード（`` ` `` で囲んだ部分）とその前後の日本語との間も同様に空けない。ファイルパスや値をバックティックで示すときも、直前・直後の助詞にそのまま続ける。
  良い例：`LLMが`、`HTTPステータス`、`APIを呼ぶ`、`references/orthography.md`を参照する
  良い例（数字）：`2倍`、`3件`、`10分`
  悪い例：`LLM が`、`HTTP ステータス`、`API を呼ぶ`、`references/orthography.md` を参照する

## 漢字とひらがなの使い分け

形式名詞、補助動詞、補助形容詞、接続詞、副詞はひらがなで書く。

| 漢字表記（使わない） | ひらがな表記（使う） | 分類 |
| --- | --- | --- |
| 事 | こと | 形式名詞 |
| 時 | とき | 形式名詞 |
| 為 | ため | 形式名詞 |
| 出来る | できる | 補助動詞 |
| 下さい | ください | 補助動詞 |
| 無い | ない | 補助形容詞 |
| 様々 | さまざま | 副詞 |
| 更に | さらに | 副詞 |
| 及び | および | 接続詞 |
| 但し | ただし | 接続詞 |
| 又は | または | 接続詞 |

固有の意味を持つ実質名詞・動詞（「事件」「無効」「更新」など）は漢字のままでよい。上の表は、同じ字面が形式的な用法で使われる場合の指定である。

## 送り仮名

- 行う（「行なう」とはしない）
- 申し込み（文中の表記。システムの表示名が「申込み」の場合はその表示名をそのまま使う）
- 取り消し
- 問い合わせ

## 数字

- 半角アラビア数字で書く（全角数字を使わない）。
- 4桁以上の数量は3桁ごとに半角カンマで区切る。例：`12,345`、`1,000,000`。年、番号、ID、コード値（`2026`年、ポート`8080`、`v1.2.3`など）は区切らない。
- 範囲は波ダッシュ「〜」（U+301C）でつなぐ。全角チルダ「～」（U+FF5E）は使わない。例：`3〜5件`、`2026-08-06〜2026-08-10`

## 記号

- 句読点は「、」「。」を使う。
- 感嘆符（！）は使わない。疑問符（？）は、疑問形の見出しなど文体上自然な場合に限り許容する。
- 三点リーダは「……」（2文字分）を使う。「...」や「…」1文字は使わない。
- 中黒（・）は、単一の固有名詞の内部（例：「サン・マイクロシステムズ」）と、見出し、「PR・Issue」「日付・時刻」のような密結合な2語の対句でのみ使う。本文中の3語以上の並列には読点を使う。
- ダッシュ（emダッシュ「—」、horizontal bar「―」、2倍ダッシュ「——」）は使わない。挿入は括弧に、言い換えは句点で二文に分けるか読点でつなぐ形に置き換える。
- 丸括弧は全角「（）」を使う。コードブロック、コマンド、変数名の内部は半角「()」のまま変更しない。
- 装飾目的の絵文字（🚀🎯✨💡など）は使わない。UI文言で状態を示す目的（✅❌など）で使う場合のみ、チームで用途を限定して許容する。

## 日付・時刻

- 日付は`2026-08-06`の形式で書く。時刻は`14:30`（24時間表記）で書く。
- 「先日」「今月」「最近」のような相対表現は、確定できる日付に置き換える。ドラフト段階で確定できない場合は`TODO: 日付確定`を残す。

## 用語統一表

| 表記（使う） | 表記（使わない） | 備考 |
| --- | --- | --- |
| ログイン | ログオン、サインイン | 社内システムの表示に合わせる |
| ユーザー | ユーザ | 長音を付ける |
| サーバー | サーバ | 長音を付ける |
| 参照する | 参照を行う | 冗長表現を避ける |
| 削除する | 削除を実施する | 冗長表現を避ける |
| 設定する | 設定を行う | 冗長表現を避ける |

レビューで表記が割れた語は、決定した表記をこの表に追記し、備考に決定日を書く。
