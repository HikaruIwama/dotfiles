# 表記と敬語の決め事

文の組み立て方からは決まらない、表記、文体、敬語の決め事をまとめた。理屈で導けないので、一覧で管理する。

## カタカナ語の長音とスペース

- カタカナ語の末尾長音は付ける。サーバー、ユーザー、コンピューター、フォルダー。
  ただし、慣用で定着している語は例外にする：セキュリティ、プロパティ、エンジニア。
  それ以外で迷った語は、長音を付けた形で用語統一表に足し、以後はそれに従う。
- 英字と日本語の間にスペースを入れない。数字と日本語の間にも入れない。インラインコード（`` ` ``で囲んだ部分）と前後の日本語の間も空けない。ファイルパスや値をバックティックで示すときも、前後の助詞にそのまま続ける。
  良い例：`LLMが`、`HTTPステータス`、`APIを呼ぶ`、`references/conventions.md`を参照する
  良い例（数字）：`2倍`、`3件`、`10分`
  悪い例：`LLM が`、`HTTP ステータス`、`API を呼ぶ`、`references/conventions.md` を参照する

## 漢字とひらがなの使い分け

形式名詞、補助動詞、補助形容詞、接続詞、副詞はひらがなで書く。

| 漢字表記（使わない） | ひらがな表記（使う） | 分類 |
| --- | --- | --- |
| 事 | こと | 形式名詞 |
| 時 | とき | 形式名詞 |
| 為 | ため | 形式名詞 |
| 出来る | できる | 補助動詞 |
| 下さい | ください | 補助動詞 |
| 無い | ない | 補助形容詞 |
| 様々 | さまざま | 副詞 |
| 更に | さらに | 副詞 |
| 及び | および | 接続詞 |
| 但し | ただし | 接続詞 |
| 又は | または | 接続詞 |

「事件」「無効」「更新」のように、その字が中身のある意味で使われている語は漢字のままでいい。上の表は、同じ字が形式的に使われるときだけの話だ。

## 送り仮名

- 行う（「行なう」とはしない）
- 申し込み（文中の表記。システムの表示名が「申込み」なら、表示名はそのまま使う）
- 取り消し
- 問い合わせ

## 数字

- 半角アラビア数字で書く（全角数字を使わない）。
- 4桁以上の数量は3桁ごとに半角カンマで区切る。例：`12,345`、`1,000,000`。年、番号、ID、コードの値（`2026`年、ポート`8080`、`v1.2.3`など）は区切らない。
- 範囲は波ダッシュ「〜」（U+301C）でつなぐ。全角チルダ「～」（U+FF5E）は使わない。例：`3〜5件`、`2026-08-06〜2026-08-10`

## 記号

- 句読点は「、」「。」を使う。
- 感嘆符（！）は使わない。疑問符（？）は、疑問形の見出しのように自然な場合だけ使っていい。
- 三点リーダは「……」（2文字分）を使う。「...」や「…」1文字は使わない。
- 中黒（・）は、一つの固有名詞の中（例：「サン・マイクロシステムズ」）、見出し、「PR・Issue」「日付・時刻」のような2語の決まった組み合わせにだけ使う。本文で3つ以上並べるときは読点を使う。
- ダッシュ（emダッシュ「—」、horizontal bar「―」、2倍ダッシュ「——」）は使わない。挟み込みたい説明は括弧に入れ、言い換えは句点で二文に分けるか、読点でつなぐ。
- 丸括弧は全角「（）」を使う。コードブロック、コマンド、変数名の中の半角「()」はそのままにする。
- 装飾目的の絵文字（🚀🎯✨💡など）は使わない。UI文言で状態を示すため（✅❌など）なら、用途を決めたうえで使っていい。

## 日付・時刻

- 日付は`2026-08-06`の形式で書く。顧客向け文書では「2026年8月6日」の形式で書く。時刻は`14:30`（24時間表記）で書く。
- 「先日」「今月」「最近」のような相対的な言い方は、具体的な日付にする。下書きで日付が決まらないなら`TODO: 日付確定`を残す。

## 用語統一表

| 表記（使う） | 表記（使わない） | 備考 |
| --- | --- | --- |
| ログイン | ログオン、サインイン | 社内システムの表示に合わせる |
| わかる | 分かる、解る | ひらがなで書く |

レビューで表記が割れた語は、決めた表記をこの表に足し、備考に決めた日を書く。

## 文体

一つの文書で、敬体（です・ます）と常体（だ・である）を混ぜない。どちらにするかは`SKILL.md`の「文書の種類ごとの文体」で決める。引用、UI文言の例、箇条書きの体言止めは混ぜたうちに数えない。

## 敬語

| よく出る形 | 直し方 | 理由 |
| --- | --- | --- |
| 〜させていただきます（多用） | ふつうの敬体（〜します）で足りることが多い | 敬語の使いすぎ |
| 拝見させていただきました | 拝見しました | 二重敬語 |
| おっしゃられました | おっしゃいました | 二重敬語 |
| 〜に関しまして | 〜について | 丁寧さを足しても意味が変わらず、長くなるだけ |
