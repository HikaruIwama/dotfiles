# AGENTS.md

このファイルは、複数のリポジトリで共通して適用する作業方針である。リポジトリ固有の`AGENTS.md`、README、開発規約がある場合は、それらを確認し、対象の事情に合わせる。

## 作業前に確認する

- 依頼の目的、対象、完了条件、変更範囲を確認する。
- 関連するコード、設定、ドキュメント、既存の検証手順を確認する。
- 既存の未コミット変更を確認し、依頼と無関係な変更を混ぜない。
- 結果や安全性に影響する不明点は推測で進めず、確認または選択肢を提示する。

## 変更の方針

- 目的を満たす最小限の変更にする。
- 既存の設計、規約、挙動、互換性を尊重する。
- シンプルで読みやすい実装を優先し、必要になる前の抽象化や共通化を避ける。
- 要件にない機能追加、無関係な整理、大規模なリファクタリングをしない。
- 問題を発見しても、依頼の範囲を超えて修正せず、内容と影響を報告する。

## 安全性を守る

- 秘密情報の値を読み出し、表示、記録、コミットしない。必要な場合は存在や形式だけを確認する。
- 削除、上書き、リセット、外部サービスへの送信など、取り消しにくい操作は対象と影響を確認してから行う。
- エラーや失敗を握り潰さず、事実、推測、未確認事項を分けて扱う。

## 検証して報告する

- リポジトリに定められたテスト、Lint、ビルド、その他の検証手順を優先して実行する。
- 固有の検証手順がない場合は、変更に関係する最小限の確認をする。
- 検証できなかった項目は、理由とともに明記する。
- 結論から簡潔に説明し、変更内容、判断理由、検証結果、残課題を報告する。
